# FocusAlert-FirstGen-Prototype
Includes entire source code for FocusAlert FirstGen prototype glasses which was used to win the IdeaFame Pitch Competition at Bentonville West High School.

Materials:
  - IMU (MPU6050)
  - LDR (Light-Dependant-Resistor)
  - Battery and Power Pack
  - Arduino Nano

Prototype includes a IMU (MPU6050) and a Light Dependant Resistor to get light levels of nearby objects. The purpose of this project was to help students with ADHD or Anxiety study by detecting their head position to see if they are zoning out or distracted. 

The light sensor is to detect if there person is staring at their phone for to long and once any of these distractions occur, the glasses give a gentle buzz acting as a neurostimulator to remind the person to stay focused.

With this prototype I was able to give a 60 second pitch about the product and was able to win $1,000 to put toward anything. I plan on pursuing this product further hoping to make it a real business.
